# SculptorPro

SculptorPro — локальное приложение для подготовки видеоэссе, шортсов и монтажных проектов на базе индексированной медиатеки. Программа помогает разобрать исходные фильмы на сцены, эпизоды и персонажей, сопоставить закадровый текст с подходящими фрагментами, собрать таймлайн и экспортировать результат для дальнейшего монтажа.

Приложение состоит из FastAPI-бэкенда в `src/` и Electron + React интерфейса в `ui/`.

## Основные возможности

### Медиатека

- Добавление исходного фильма или видеофайла в библиотеку.
- Индексация источника: детекция сцен, исправление коротких мерцаний, поиск лиц, генерация CLIP-эмбеддингов и сборка `master_index.json`.
- Отображение готовности источника и прогресса обработки в реальном времени.
- Постеры через TMDB при наличии `TMDB_API_KEY`; fallback на кадры/лица из локального индекса.
- Поиск по фильмам, путям и группам.
- Удаление источников из библиотеки.
- Восстановление пути к исходному видео, если файл был перемещен.

### Эпизоды, персонажи и группы

- Ручное создание, редактирование и удаление эпизодов по таймкодам.
- Автоматическая нарезка источника на эпизоды через AI в выбранном диапазоне времени.
- Загрузка сценария фильма в формате `.txt` или `.pdf` для более точной аналитики и сегментации.
- Просмотр найденных персонажей.
- Создание групп из эпизодов и персонажей разных источников. Группы можно использовать как готовые смысловые блоки при сборке проекта.

### Анализ решений персонажей

- Анализ решений выбранного персонажа по цели или мотивации.
- Сохранение и просмотр ранее созданных анализов для конкретного источника.
- Использование загруженного сценария как дополнительного контекста, если он есть.

### Проекты

- Создание монтажных проектов типа `segmented`.
- Загрузка или запись закадровой аудиодорожки.
- Создание проекта из аудио, подготовленного в Studio.
- Транскрибация аудио проекта через Whisper.
- Просмотр waveform и расстановка клипов на таймлайне.
- Добавление на таймлайн:
  - эпизодов из медиатеки;
  - персонажей;
  - групп;
  - разных режимов подбора фрагментов.
- Ручное редактирование клипов: позиция на таймлайне, длительность, режим матчинга.
- Магнитная привязка границ клипов к сегментам транскрипта.
- Автоплан таймлайна по тексту сценария с выбором Gemini-модели.
- Сохранение сегментированного таймлайна в `project_meta.json`.
- Сборка проекта в XML для дальнейшего импорта в монтажный софт.
- Отслеживание прогресса сборки через WebSocket.
- Удаление одного или нескольких проектов.

### Music Studio

- Разбор полного сценария на музыкальные смысловые блоки.
- Генерация Suno-ready тегов и промптов для каждого блока.
- Копирование промптов и тегов для ручной работы.
- Авторизация в Suno через Electron и запуск генерации инструментальных треков.
- Сохранение треков в общей папке Studio.
- Прослушивание и удаление сгенерированных треков.
- Добавление фоновой музыки в конкретный проект.

### Озвучка и перевод

- Получение списка голосов ElevenLabs по API-ключу.
- Генерация TTS-аудио в проект или Studio.
- Транскрибация загруженного аудио.
- Перевод текста через Gemini.

### Shorts Generator

- Загрузка видео для генерации шортсов.
- Автоматический поиск сильных фрагментов.
- Настройка количества клипов, минимальной и максимальной длительности.
- Включение или отключение субтитров.
- Выбор готового стиля субтитров или настройка кастомного цвета, обводки, размера и отступов.
- История задач, предпросмотр, скачивание и удаление готовых клипов.

### Trends

- Получение трендовых видео YouTube по региону и категории.
- Поиск вирусных видео по ключевым словам.
- Фильтрация по периоду, региону, категории и outlier-роликам.
- Расчет virality score, скорости просмотров, engagement rate и outlier ratio.
- AI-анализ списка видео с выделением микрониш, причин вирусности, сложности и вариантов монетизации.

### Brainstorm Shorts

- Генерация идей для YouTube Shorts по названию фильма.
- Фокус на спорных, неочевидных или парадоксальных тейках.
- Генерация короткого сценария по выбранной идее: хук, аргументация и вывод.

## Как устроены данные

Исходный код хранится в этом репозитории. Рабочие данные приложения хранятся отдельно, чтобы не смешивать код, видео, индексы и результаты.

Путь к данным:

- macOS / Windows: `~/Documents/SculptorPro`
- Linux: `~/.sculptorpro`

Основные папки:

- `_library/` — индексированные источники: сцены, лица, эмбеддинги, эпизоды, сценарии и метаданные.
- `projects/` — монтажные проекты, входное аудио, артефакты и экспорт.
- `_studio/` — общая Studio-папка для аудио и музыки.
- `config.yaml` — локальная конфигурация моделей и путей.

## Требования

- Python 3.9+
- Node.js 18+
- npm
- `ffmpeg` и `ffprobe` для аудио, waveform, транскодирования и обработки видео.

Для части AI-функций нужны дополнительные ключи:

- `GOOGLE_API_KEY` — Gemini: автоплан таймлайна, Brainstorm, перевод, музыкальный анализ.
- `YOUTUBE_API_KEY` — YouTube Trends.
- `TMDB_API_KEY` — постеры фильмов в медиатеке.
- ElevenLabs API key вводится в интерфейсе при генерации TTS.
- Suno использует авторизацию через Electron-сессию.

## Установка

### Backend

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

Если нужен вариант через зафиксированные runtime-зависимости:

```bash
python -m pip install -r requirements.txt
python -m pip install -e ".[dev]"
```

### Frontend

```bash
cd ui
npm install
```

### Переменные окружения

```bash
cp .env.example .env
```

Заполните только те ключи, которые нужны для вашего сценария:

```env
GOOGLE_API_KEY=
YOUTUBE_API_KEY=
TMDB_API_KEY=
```

## Запуск

Запустить все приложение:

```bash
make start
```

Это выполнит `./SculptorPro.sh`: поднимет backend на `127.0.0.1:8000`, дождется `/status` и запустит Electron UI через Vite.

Запуск по частям:

```bash
make run-backend
```

```bash
make run-ui
```

Проверка backend:

```bash
curl http://localhost:8000/status
```

Логи пишутся в:

- `logs/backend.log`
- `logs/frontend.log`

## Базовый рабочий процесс

1. Откройте приложение и перейдите в `Library`.
2. Нажмите `Ingest Movie`, выберите исходный видеофайл и задайте короткий alias.
3. Дождитесь завершения индексации.
4. Откройте источник, создайте эпизоды вручную или запустите auto-segmentation.
5. При необходимости загрузите сценарий `.txt` или `.pdf`.
6. Создайте группы из эпизодов и персонажей, если хотите собирать проект из повторяемых смысловых блоков.
7. Перейдите в `Projects` и создайте новый проект.
8. Загрузите или запишите voiceover.
9. Транскрибируйте аудио.
10. Перетащите эпизоды, персонажей или группы на таймлайн либо используйте автоплан.
11. Сохраните таймлайн.
12. Запустите сборку проекта и получите XML в папке `projects/<project>/output/`.

## Важные backend endpoints

- `GET /status` — состояние backend и количество источников в библиотеке.
- `GET /library` — список источников.
- `POST /ingest` — запуск индексации источника.
- `GET /library/{alias}/episodes` — список эпизодов.
- `POST /library/{alias}/auto-episodes` — AI-сегментация эпизодов.
- `POST /library/{alias}/screenplay` — загрузка сценария.
- `GET /groups` / `POST /groups` — работа с группами.
- `GET /projects` / `POST /projects/create` — список и создание проектов.
- `POST /projects/{name}/audio/transcribe` — транскрибация аудио проекта.
- `PUT /projects/{name}/segmented_timeline` — сохранение таймлайна.
- `POST /projects/{name}/segmented_timeline/auto_plan` — автоплан таймлайна.
- `POST /projects/{name}/build_segmented` — сборка XML.
- `GET /ws/logs` — WebSocket для логов и прогресса.
- `POST /shorts/generate` — генерация шортсов.
- `GET /youtube/trending` и `GET /youtube/search` — тренды и поиск YouTube.
- `POST /brainstorm/ideas` и `POST /brainstorm/script` — идеи и сценарии для Shorts.
- `POST /music/script_plan` и `POST /music/generate` — музыкальные блоки и генерация треков.

## Примечания

- Приложение рассчитано на локальную работу с тяжелыми медиафайлами; runtime-данные не должны попадать в git.
- Некоторые функции зависят от внешних API и будут недоступны без соответствующих ключей.
- ML-зависимости вроде Whisper, CLIP, face detection и PyTorch могут быть тяжелыми; часть тестов и сценариев пропускается или падает, если optional-пакеты не установлены.
- Для стабильной обработки видео и аудио убедитесь, что `ffmpeg` доступен в `PATH`.
